# Security policy

## Supported versions

Only the [latest release](https://github.com/kaharamamm/Lore-Forge/releases/latest) gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Use **[Report a vulnerability](https://github.com/kaharamamm/Lore-Forge/security/advisories/new)** on the repository's Security tab, or send a private message to me ([@kaharamamm](https://github.com/kaharamamm)) on GitHub. Include the version, your system and steps to reproduce.

You should get an answer within a week. Lore-Forge is developed and maintained by one person, so fixes may take longer; you'll be kept informed.

## Scope

Lore-Forge runs on your computer. It goes online only to check for updates (the automatic check can be turned off under About) and to reach a picture service or AI app when you connect one. The most relevant issues are a world folder or a shared book file (.loreforge) that can make the app read or write files outside the book's folder, run code, or crash the app when opened.
